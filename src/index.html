▸ Method

Five steps from raw list to ranked board.

  1. Collect

    Pull the promoted list

    One request returns names that carry paid promotion, across every network.

  2. Filter

    Keep Solana only

    Entries from other networks drop out before anything else happens.

  3. Resolve

    Find the deepest pool

    A pair lookup returns each name's pools. The one holding most liquidity speaks for it.

  4. Rank

    Sort by day volume

    Ten names holding peak twenty-four hour turnover make the cut.

  5. Refresh

    Repeat each minute

    Polling sleeps while the tab is hidden and resumes on return. Failures retry with growing pauses while earlier numbers stay put.
